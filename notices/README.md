# Notices

Attribution and license notices for third-party code that Wayland builds on. Everything in this
directory ships inside the packaged application, alongside the `LICENSES/` directory at the
repository root.

- [THIRD-PARTY-NOTICES.md](./THIRD-PARTY-NOTICES.md) - the attributions Wayland is obliged to
  carry, covering both Apache-2.0 and MIT upstreams.
- [Apache-2.0.txt](./Apache-2.0.txt) - verbatim text of the Apache License, Version 2.0, included
  to satisfy Section 4(a) for the Apache-2.0 upstreams. Do not edit or reformat this file; it must
  remain a verbatim copy.
- [OfficeCLI-NOTICE.txt](./OfficeCLI-NOTICE.txt) - the upstream OfficeCLI NOTICE file, reproduced
  verbatim as Section 4(d) requires.
- [OfficeCLI-THIRD-PARTY-NOTICES.txt](./OfficeCLI-THIRD-PARTY-NOTICES.txt) - notices for the
  components OfficeCLI itself bundles.
- [7zip-bin-MIT.txt](./7zip-bin-MIT.txt) - MIT text for the bundled 7zip-bin binaries.

The per-upstream MIT texts that source-file headers cite by path live in `LICENSES/` at the
repository root, not here.

Wayland itself is licensed under the GNU AGPL-3.0 ([LICENSE](../LICENSE) at the repository root).
The licence texts in this directory cover the upstream code only and grant nothing in respect of
Wayland's own source.
